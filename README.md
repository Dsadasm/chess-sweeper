# Chess Sweeper

Chess Sweeper is like Mine Sweeper but mines are repleaced by chess pieces.


![image](public/screenshot1.png)
![imgae](public/screenshot2.png)

## Installation

### Prerequisites
- Node.js
- npm

### Setup
```bash
git clone https://github.com/Dsadasm /chess-sweeper.git
cd chess-sweeper

npm install

npm run dev
```
